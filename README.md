# WPFDreiDWuerfel

Ein Visual-Studio-Projekt zur Einführung in die dreidimensionale Grafikdarstellung mit Windows Presentation Foundation (WPF).

## Beschreibung

Das Projekt **WPFDreiDWuerfel** beschäftigt sich mit den Grundlagen der 3D-Grafikprogrammierung in WPF. Im Mittelpunkt stehen die Erstellung und Darstellung eines dreidimensionalen Würfels sowie die Verwendung geometrischer Modelle und räumlicher Koordinaten innerhalb einer grafischen Benutzeroberfläche.

## Funktionen

- Darstellung eines dreidimensionalen Würfels
- Verwendung von 3D-Geometrien
- Positionierung von Objekten im dreidimensionalen Raum
- Grundlagen der Perspektive und Kameradarstellung
- Einführung in die dreidimensionale Grafikprogrammierung mit WPF

## Technologien

- Microsoft Visual Studio
- C# / .NET
- Windows Presentation Foundation (WPF)
- XAML
- WPF 3D-Grafik

## Installation und Ausführung

1. Repository klonen:

   ```bash
   git clone https://github.com/samad-pour/WPFDreiDWuerfel.git
   ```

2. Die Datei `WPFDreiDWuerfel.sln` in Visual Studio öffnen.
3. Das Projekt erstellen.
4. Die Anwendung mit `F5` starten.
